# Public release checklist

- [ ] Confirm permission to publish each team member's contribution.
- [ ] Review all staged files for passwords, tokens, personal domains, student IDs and database dumps.
- [ ] Remove unrelated lecture files and private class data.
- [ ] Check that the actual remote firmware matches the server receiver mode.
- [ ] Obtain genuine KiCad schematic/PCB files from the hardware author.
- [ ] Execute unit/integration tests and a physical BLE transaction test.
- [ ] Confirm that no undocumented Cloud, AI or multi-remote test claims are presented as validated.
- [ ] Review privileged `deploy/install_ubuntu.sh` before deployment.
