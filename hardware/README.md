# nRF52840 remote hardware

The group report describes a two-layer **68 × 80 mm** custom PCB with nRF52840 SuperMini, 14 keys in a 4 × 4 keypad matrix, a two-digit 7-segment display, a red/green status indicator and power from two AA cells through polarity protection and a 5 V boost module into the module's USB-C input.

**Missing source:** Editable KiCad schematic (`.kicad_sch`) and PCB (`.kicad_pcb`) files are not included in the uploaded server archive. The report images are not a replacement for editable hardware sources. Do not publish fabricated design files.

Before using the hardware in a reproduction, verify the module power path and RF antenna keepout.
